Hi, welcome to PhononOS, and OS made to be as light as possible, dont expect crazy shit yet tho, its as bare-metal as it can be. Tho theres no usb support yet, no networking software and no desktop environement. So if you arent familiar with code i wouldn't recommend it. Now heres the commands: power_sw 0x0(shutdown), ls(list files), rd(read the file you want(rd:filename)), wr(write data(wr:filename:data)) and echo(echo:message)
